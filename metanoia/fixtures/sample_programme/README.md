# Sample programme pack

Neutral sample content for `manage.py seed_sample_programme` and its tests. It shows the
folder layout the programme-pack importer reads (see `core/programme_pack/scanner.py`):
a student pack and a tutor pack, a Start here folder, dated teaching weekends with one
folder per module unit, and a mini mock. None of it is real teaching material; the dates
are examples. Replace it with a real pack, or point the command at one with `--pack`.
