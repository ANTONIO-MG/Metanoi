{% extends 'myhub/elements/layouts/admin.html' %}{% load people %} {% comment %} One session's own page — the link that goes in the calendar, the reminders and the e-mails. Before it happens: details and a Join button. Afterwards the same page grows the recording player, transcript, recap and session pack — so the link sent before the class keeps working after it. Business rules carried by the markup: - Recordings: students and parents watch here only — no download button, the player's own download menu hidden, no right-click "Save video". Staff and educators keep the download (owner, 2026-11-09). - Every recording/material link stays on our own domain: the OneDrive share links land students on a Microsoft sign-in page. Staff keep the OneDrive copies, marked as such. - Join: Teams asks anonymous joiners to type a name, and Microsoft offers no supported way to pre-fill it, so the page shows the exact name to paste. Identity is already recorded server-side; this only makes the Teams-side report agree. - The calendar (.ics) download: the Microsoft invite only goes to licensed staff (see ``graph.create_calendar_event``) and not at all while Teams is off, so this download is a student's way to get the session into their diary. - Session pack: the full pack (roster, educator actions, flags) is staff material; the class reads the student version, which is what the recap holds once the pack exists. The script: - Puts the join name on the clipboard as they leave (the Join button), so the Teams name box is a paste rather than a retype. Best effort — the link works regardless, and Metanoia has already recorded who clicked it. ``#copyName`` copies it on demand. - "Copy joining link" copies the session page URL, for pasting into a chat or a channel. It is the session page rather than the raw Teams URL on purpose: that route is identified, so attendance is still recorded for whoever follows it (see ``session_join``). - Recovers an expired recording link (see ``reload`` in the script).{% endcomment %} {% block additional_css %} {% endblock %} {% block content %}
