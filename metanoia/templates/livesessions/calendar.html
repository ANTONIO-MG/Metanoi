{% extends 'myhub/elements/layouts/admin.html' %} {% comment %} The Metanoia calendar — one month, one query. Scoped by livesessions.audience.visible_sessions(). All times render in the reader's own zone: UserPreferenceMiddleware has already activated it, so `{{ x|time }}` is local without any per-view conversion. Inline styles: - Grid columns use ``minmax(0,1fr)``, not a bare ``1fr``: a plain ``1fr`` track's floor is the widest thing inside it (a whole un-wrappable title), and seven of those pushed the grid past the page. A zero floor lets each column keep its seventh. - Every day cell is the same fixed height — ``CELL_LIMIT`` items and a "+N more" line — so a busy day never stretches its week, or the month, down the page. ``min-width:0`` because a grid item's automatic minimum is its content. - The popup shows one item, or a day's whole list. - Phones: seven text columns cannot be read at 390px, so each day shows its icons only — tap the day for the list. The legend doubles as the filter — every source can be toggled off, and the choice rides in ``?show=`` so a filtered month is a shareable link. Every item is a button: it opens the popup with the whole entry (full title, time, module, where, what it is) and a link through to it. Items come from ``views._calendar_item``; the popup reads ``#calDays``. On phones a tap on the day cell itself (icons only) opens the day's list. The month is swapped in by htmx on sidebar navigation, so the script lifts this month's popup onto ```` (clear of the content column's stacking), drops the previous month's and binds the click handler only once (``window.__calPopBound``).{% endcomment %} {% block additional_css %} {% endblock %} {% block content %}
