Images are inline (``cid:``) parts attached by send_branded_email and the allauth adapter: ``inline.sig_avatar``, ``inline.sig_logo``, ``inline.banner``. No {% templatetag openblock %} url {% templatetag closeblock %} tags here on purpose — this template must render whoever calls it, including allauth with no request in context. Children provide: • email_heading — big title (context var, or override block "heading") • block "content" — the body paragraphs • cta_url / cta_label — the button (or override block "cta") • block "disclaimer" — small print under the body (e.g. "didn't request this?") • block "expiry_note" — grey small-print note (e.g. link-expiry line) • preheader — hidden inbox-preview text (context var, or override block "preheader") Montserrat is named first everywhere; clients without it fall back to Helvetica/Arial.
