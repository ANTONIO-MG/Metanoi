{% load static %} {% comment %}First-paint theme, before any CSS draws. The server stamps from the user's saved choice (light or dark), so when it is there it is the truth: a user who chose dark always gets dark. With no stamp ("auto", or signed out) the browser's last choice from the theme switch applies (js/theme.js keeps it under "metanoiahub.theme"); "auto" follows the device; and with no choice at all the platform is light. When the script decides the theme it also sets ``data-theme-client="1"``, marking the theme as chosen in the browser rather than by the server. Reading ``localStorage`` is wrapped in ``try``: it throws in private mode.{% endcomment %}
