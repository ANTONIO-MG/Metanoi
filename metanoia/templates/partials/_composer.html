{% load static %} {% comment %}"Share your thoughts" composer — posts to the unified feed (text + one or more photos/videos/files). Every picked file, from either button, is collected into the single hidden `media` input (via DataTransfer) so the post can carry several attachments. The post goes to the community picked below (the one being viewed by default); type @ to tag somebody in that community. Community members may attach photos only (``member_limits`` is set for them). The tiles strip shows the selected attachments (thumbnails / file chips, each removable before posting); ``.composer-final`` is the field actually submitted, and every picked file is copied into it. The optional module select files the post under a module so the feed's module filter can find it; the community select sets which community the post goes to — everyone in it can see the post. The text box starts at two lines and grows / shrinks with the text (the script sets its height on input), capped at 22rem so a long post never pushes the Post button off-screen; ``min-height`` keeps the two-line floor after the text is deleted. Each pick input is cleared after its files are collected, so the same file can be chosen again later.{% endcomment %}
