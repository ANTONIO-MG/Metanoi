Import content into a programme

Choose the programme and cohort, then upload the pack as one zip — the student pack and, beside it, the tutor pack. The content goes into that programme's existing modules: nothing new is created, and a module folder that does not match one of the programme's modules stops the build. The folders are the structure: a Start here folder becomes onboarding, each dated weekend / week folder a week, each MODULE_Unit_n_Title folder a unit lesson, a Mocks folder the mock weeks, a Blueprint folder the blueprint lessons. Student-pack files go to students; tutor-pack files stay with tutors and staff.

What folders cannot say — session times, extra sessions, exam and deadline dates, unit titles, mock papers — comes from the schedule sheet (0_Start_Here/schedule.csv in the pack, or uploaded below){% if ai_enabled %}, or the AI drafts it from the timetable for you to check{% endif %}. Uploading a new version of a pack already built updates it in place: students keep their progress. Nothing is built until you have checked the next page.

What goes in the sheet

One row per item. Columns: type, module, number, date, end, time, minutes, kind, title, details. Types: phase (which test / exam block this is), slot (a module's weekly session), session (a one-off session), date (a calendar date), unit, week, mock_paper, document, host.
