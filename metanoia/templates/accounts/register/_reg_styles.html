Sections, in order: - Section header (``.rf-sec``): chevron + title + completion check, drawn in CSS with no icon font. The chevron points down when collapsed (click to open), up when expanded; the check is a green circle with a CSS-drawn tick once the section is done (dashed for optional sections). Bootstrap's own accordion chevron is hidden — ours sits on the left. - Section icon header (``.rf-icon-head``) for the non-accordion pages (parent / educator / checkout). - Fields (``.rf-label``, ``.req``, ``.rf-help``, ``.rf-err``) and the green tick (``.wz-ok``) on a valid required input. - Phone number with country-code picker (``.phone-field``, ``.phone-menu``). The menu is ``position: fixed`` and the script moves it to ```` while it is open: the accordion section it lives in is ``overflow-hidden`` (for its rounded corners), which would otherwise crop the list at the fold, and an absolute menu would also be trapped by any transformed ancestor. Ten rows show before it scrolls — ``.phone-opt`` is pinned to 2.2rem so the count is exact. - Round profile-picture preview (``.pfp-preview``). - Horizontal pill radios (guardian relationship, mode of study): the real radio is visually hidden and the pill label is the control. - Toggle switches (``.rf-switch``): green on, red off. - Summary card (``.rf-summary``) for checkout / review.{% endcomment %}
