Validation: a required field gets the green tick (``.wz-ok``) once it is filled and valid; a section is marked done (``.sec-done``) when all its required fields are, or optional (``.sec-optional``) when it has none. Phone picker (``[data-phone-field]``, see _phonefield.html): - On load it shows the country whose code the saved number already starts with, so re-opening a completed form does not silently relabel the number. - Choosing a country swaps the old dialling code for the new one, keeping what was typed. - While open, the menu is moved to ```` so the accordion's ``overflow: hidden`` cannot crop it, and is positioned by hand against the field's viewport rectangle — below by preference, flipping above only when there is genuinely more room there — and kept stuck to the field while the page (or a scrollable parent) scrolls. On close it goes back into the field. - Because the open menu is a child of ````, not of the field, the outside-click test checks both — or the list would shut the moment you reached for the search box. - The dialling code stays pinned to the front of the input, so typing a bare local number still submits a complete international one.{% endcomment %} {% load reg_tags %}
